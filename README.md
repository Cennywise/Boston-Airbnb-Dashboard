# Boston Airbnb Dashboard

[Link to Tableau Project](https://public.tableau.com/views/BostonAirbnbDashboard_17550440979620/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

I downloaded a dataset of [Boston Airbnb's](https://www.kaggle.com/datasets/airbnb/boston) and used Tableau to build an interactive dashboard showing which ZIP codes charged the highest rent, which times of year earned the most revenue, and the rent difference that different numbers of bedrooms made. The goal was to gain insight into what kind of Boston property would be most lucrative as an investment. I found that the ZIP code 02142 charges the highest rent. Airbnb's with 4 bedrooms have the highest median price, even higher than 5 bedroom properties, and Thanksgiving is the most lucrative time of year.
